\# Automated Copywriting \& Tone Transformer



\## Description



Automated Copywriting \& Tone Transformer is a Python-based Generative AI project that generates marketing copy from a raw product description.



The application accepts a Product Name, Product Description, Platform, Tone, Temperature, and Top\_P. It can create platform-specific marketing content for LinkedIn, Instagram, and Email.



The project also includes a Demo Mode for testing the application without API credits.



\## Features



\- Platform-specific marketing copy

\- Tone-based content generation

\- Dynamic prompt creation

\- Temperature control

\- Top\_P control

\- Input validation

\- OpenAI API integration

\- Local Demo Mode
